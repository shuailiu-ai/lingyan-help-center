在 Edge 中点击下方按钮，可直接进入插件详情页，随后按第 3 步完成安装。也可以按下方步骤，在商店中搜索插件。

<ActionButton href="https://microsoftedge.microsoft.com/addons/detail/pfjjocoeejpldpfhpijgpbpfcbbeidbp">
  添加到 Edge
</ActionButton>

如果无法通过 Edge 加载项商店安装，可以[查看手动安装教程](/docs/plugin/manual-install)。

## 1. 打开 Edge 加载项商店

打开 Edge，点击右上角的“更多”（三个点）按钮，依次选择“扩展”→“获取 Microsoft Edge 扩展”。

![在 Edge 更多菜单中选择扩展，再点击获取 Microsoft Edge 扩展](/images/plugin/edge/open-store.png)

也可以复制下方的 Edge 加载项商店地址，粘贴到 Edge 地址栏后按回车。代码块右上角提供复制按钮。

```text
https://microsoftedge.microsoft.com/addons/Microsoft-Edge-Extensions-Home
```

## 2. 搜索灵研 AI

在商店顶部的搜索框输入“灵研AI”，按回车键搜索。

![Edge 加载项商店首页及顶部搜索框](/images/plugin/edge/store-home.png)

搜索结果中可能包含其他插件。找到“灵研AI - 科研人专属的 AI 助手”，核对名称和蓝色图标后，点击卡片进入插件详情页。

![Edge 商店搜索结果中标出的灵研 AI 插件卡片](/images/plugin/edge/search-results.png)

## 3. 添加到 Edge

在插件详情页点击“获取”（英文界面显示为“Get”）。

![灵研 AI 插件详情页右上方的 Get 按钮](/images/plugin/edge/get-extension.png)

浏览器会弹出安装确认窗口。查看插件名称和权限说明后，点击“添加扩展”，等待安装完成。

![在 Edge 安装确认窗口中点击添加扩展](/images/plugin/edge/confirm-install.png)

## 4. 将插件固定到工具栏

安装完成后，点击 Edge 右上角的“扩展”（拼图）图标，找到灵研 AI，点击右侧的图钉按钮。

![打开 Edge 扩展菜单，点击灵研 AI 右侧的图钉按钮](/images/plugin/edge/pin-extension.png)

固定后，灵研 AI 图标会显示在地址栏右侧的工具栏中。看到下图中的图标，就完成了安装和固定。

![固定后的灵研 AI 图标显示在 Edge 地址栏右侧](/images/plugin/edge/pinned.png)
