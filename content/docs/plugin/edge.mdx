通过 Microsoft Edge 加载项商店可以直接安装灵研 AI 浏览器插件，并自动接收后续版本更新。

<ActionButton href="https://microsoftedge.microsoft.com/addons/detail/pfjjocoeejpldpfhpijgpbpfcbbeidbp">
  添加到 Edge
</ActionButton>

## 安装步骤

1. 打开上方的 Microsoft Edge 加载项商店页面。
2. 点击“获取”。
3. 在确认窗口中点击“添加扩展”。
4. 安装完成后，在扩展菜单中固定灵研 AI。

如果无法访问 Edge 加载项商店，可以改用[手动安装插件](./manual-install)。
