通过 Chrome Web Store 可以直接安装灵研 AI 浏览器插件，并自动接收后续版本更新。

<ActionButton href="https://chromewebstore.google.com/detail/dmhnkifagnmcjcloabnpocpdogajbadp">
  添加到 Chrome
</ActionButton>

## 安装步骤

1. 打开上方的 Chrome Web Store 页面。
2. 点击“添加至 Chrome”。
3. 在确认窗口中点击“添加扩展程序”。
4. 安装完成后，在扩展程序菜单中固定灵研 AI。

如果无法访问 Chrome Web Store，可以改用[手动安装插件](/docs/plugin/manual-install)。
