在 Chrome 中点击下方按钮，可直接进入插件详情页，随后按第 3 步完成安装。也可以按下方步骤，在商店中搜索插件。

  添加到 Chrome
</ActionButton>

国内网络可能无法直接访问 Chrome 应用商店。如果当前网络无法打开商店，可以通过手动安装的方式在 Chrome 中使用插件，具体步骤请[查看手动安装教程](/docs/plugin/manual-install)。

## 1. 打开 Chrome 应用商店

打开 Chrome，点击右上角的“更多”（三个点）按钮，依次选择“扩展程序”→“访问 Chrome 应用商店”。

![在 Chrome 更多菜单中选择扩展程序，再点击访问 Chrome 应用商店](/images/plugin/chrome/open-store.png)

也可以复制下方的 Chrome 应用商店地址，粘贴到 Chrome 地址栏后按回车。代码块右上角提供复制按钮。

```text
https://chromewebstore.google.com/
```

## 2. 搜索灵研 AI

在商店顶部的搜索框输入“灵研AI”，按回车键搜索。

![在 Chrome 应用商店的搜索框中输入灵研AI](/images/plugin/chrome/search.png)

在搜索结果中找到“灵研AI - 科研人专属的 AI 助手”，点击卡片进入插件详情页。

![搜索结果中的灵研 AI 插件卡片](/images/plugin/chrome/search-results.png)

## 3. 添加到 Chrome

在插件详情页点击“添加至 Chrome”（英文界面显示为“Add to Chrome”）。

![灵研 AI 插件详情页右上方的 Add to Chrome 按钮](/images/plugin/chrome/add-to-chrome.png)

浏览器会弹出安装确认窗口。查看插件名称和权限说明后，点击“添加扩展程序”，等待安装完成。

![在 Chrome 安装确认窗口中点击添加扩展程序](/images/plugin/chrome/confirm-install.png)

## 4. 将插件固定到工具栏

安装完成后，点击 Chrome 右上角的“扩展程序”（拼图）图标，找到灵研 AI，点击右侧的图钉按钮。

![打开扩展程序菜单，点击灵研 AI 右侧的图钉按钮](/images/plugin/chrome/pin-extension.png)

固定后，灵研 AI 图标会显示在地址栏右侧的工具栏中。看到下图中的图标，就完成了安装和固定。

![固定后的灵研 AI 图标显示在 Chrome 地址栏右侧](/images/plugin/chrome/pinned.png)
