如果无法通过 Chrome 或 Edge 插件商店安装，可以下载安装包，通过浏览器的扩展程序功能手动安装。

整个过程约 **2 分钟**。

<Cards className="grid-cols-1">
  <Card
    icon={<Download />}
    title="下载安装包（占位）"
    description="正式安装包发布后，将在这里提供下载。"
    href="#download-placeholder"
  />
</Cards>

<Callout type="info" title="开始前请注意">
  手动安装后，请保留解压后的插件文件夹。移动或删除该文件夹可能导致插件失效。
</Callout>

<Steps>

<Step>

## 下载安装包

点击页面顶部的“下载安装包”。第一阶段该链接为占位，正式安装包会在发布后补充。

</Step>

<Step>

## 解压 ZIP 文件

下载完成后解压 ZIP 文件，并将解压后的文件夹放在不容易误删的位置。

</Step>

<Step>

## 打开浏览器扩展程序页面

<Tabs items={['Chrome', 'Edge']}>
  <Tab value="Chrome">

在 Chrome 地址栏粘贴以下地址并回车：

```text
chrome://extensions/
```

  </Tab>
  <Tab value="Edge">

在 Edge 地址栏粘贴以下地址并回车：

```text
edge://extensions/
```

  </Tab>
</Tabs>

代码块右上角提供复制按钮。

</Step>

<Step>

## 开启开发者模式

在扩展程序页面找到“开发者模式”开关并开启。Chrome 通常位于右上角，Edge 通常位于左侧栏。

</Step>

<Step>

## 点击“加载已解压的扩展程序”

开启开发者模式后，点击页面上方出现的“加载已解压的扩展程序”按钮。

</Step>

<Step>

## 选择解压后的插件文件夹

在文件选择窗口中，选择刚才解压得到的插件文件夹，然后确认。

<Callout type="warn" title="不要选择 ZIP 文件">
  浏览器需要读取解压后的完整文件夹，不能直接选择下载的 ZIP 压缩包。
</Callout>

</Step>

<Step>

## 安装完成

扩展程序列表出现“灵研 AI”即表示安装成功。建议在浏览器扩展程序菜单中固定图标，方便后续使用。

</Step>

</Steps>

## 安装后没有看到图标？

查看[插件图标不显示](/docs/faq/plugin-icon-missing)中的排查方法。
