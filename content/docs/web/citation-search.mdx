引用查找会分析你提供的论文段落，识别可能需要引用的位置，并推荐相关文献。你可以决定保留哪些引用，再复制带有引用标注的原文和参考文献列表。

## 如何使用

### 1. 粘贴论文段落

在灵研 AI 左侧导航中打开“引用查找”，粘贴已经写好的论文段落，然后点击“开始查找”。

![粘贴论文段落并开始查找引用](/images/web/citation-search/start.png)

### 2. 查看推荐文献

系统会在原文中标注引用编号，并在右侧展示推荐文献。每条结果可能包含论文标题、作者、期刊或会议、摘要、发表时间及 SCI、JCR 等标签。

![查看推荐文献和文献标签](/images/web/citation-search/recommendations.png)

### 3. 调整引用

点击“添加引用”可以将文献加入当前段落；点击“取消引用”可以移除不需要的文献。需要稍后阅读的论文可以加入收藏。

![添加或取消推荐引用](/images/web/citation-search/manage-citations.png)

### 4. 选择参考文献格式

确认引用后，页面底部会生成参考文献列表。你可以切换 APA、MLA、Chicago 或 GB/T 格式。

![切换参考文献格式](/images/web/citation-search/styles.png)

### 5. 复制结果

点击“复制全文”获取带引用编号的原文，并复制生成的参考文献列表，粘贴到你的文档中。

![复制带引用的原文和参考文献](/images/web/citation-search/copy.png)

## 使用说明

- 推荐结果用于辅助查找，不代表文献一定适合你的论证。
- 使用前请阅读全文，并确认文献内容确实支持对应表述。
- 提交论文前，请按照学校或期刊要求复核引用格式和来源信息。
