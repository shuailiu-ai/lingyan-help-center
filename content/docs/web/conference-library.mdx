顶会库汇集计算机领域会议论文，支持关键词或自然语言检索、按会议和年份浏览、查看相似文献，以及筛选带有开源代码的论文。

## 如何使用

### 1. 打开顶会库

登录灵研 AI，在左侧导航中点击“顶会库”。

![从左侧导航进入顶会库](/images/web/conference-library/entry.png)

### 2. 搜索论文

在顶部搜索框输入关键词或直接描述研究问题。搜索会覆盖顶会库中已收录的会议论文。

![使用关键词或自然语言搜索顶会论文](/images/web/conference-library/search.png)

### 3. 按会议浏览

你也可以先选择 AAAI、ACL、CVPR、ICCV、ICML、IJCAI、NeurIPS 等会议，再按年份和 Track 或主题分组缩小范围。

![按会议、年份和主题分组浏览论文](/images/web/conference-library/browse.png)

### 4. 查看相似文献

打开论文阅读页并切换到“相似文献”，可以查看来自相同或其他会议的相关研究。

![在论文阅读页查看相似文献](/images/web/conference-library/related.png)

### 5. 查找开源代码

打开“仅看有代码”后，结果列表会优先显示带有代码仓库的论文。点击“Code”即可前往对应仓库，按钮旁会显示项目 Star 数等信息。

![筛选有开源代码的论文并打开代码仓库](/images/web/conference-library/code.png)

## 使用说明

会议、论文数量和代码链接会随收录情况变化。访问代码仓库后，请结合许可证和项目说明判断是否可以使用。
